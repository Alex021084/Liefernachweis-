# Dählmann Liefernachweis – Version 99

Korrektur für das Fortsetzen eines Entwurfs im Startdialog:
- Klick auf „Weiter“ wird bereits in der Capture-Phase abgefangen (iOS-Safari-Absicherung).

- Die übrigen Funktionen aus Version 98 bleiben erhalten.

`index.html` lädt `app-v99.js`. Beide Dateien gemeinsam hochladen.
